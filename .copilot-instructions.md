## 🔧 Core Principles I Always Follow

### **1. 3-Layer Architecture (MANDATORY)**

```
Request → Router → Controller → Service → Repository → Database
```

- **Router**: Define endpoints only
- **Controller**: Extract request, validate, format response
- **Service**: Business logic, validation, transformation
- **Repository**: Data access ONLY
- **Database**: Execute queries/stored procedures

**I will NEVER put business logic in repository or data access in service.**

### **2. TypeScript Type Safety**

- Always use types (interfaces)
- Never use `any` type
- Define DTOs for request/response

### **3. SQL Security**

- ALWAYS use parameterized queries with `.input()`
- NEVER concatenate SQL strings
- Prevent SQL injection at all costs

### **4. Error Handling**

- Try-catch in every async operation
- Meaningful error messages
- Sanitize errors before returning to client

### **5. Input Validation**

- Validate in service layer BEFORE persistence
- Check required fields, format, length
- Verify business rules
- Prevent duplicates

### **6. Standard Response Format**

```json
{
  "success": true/false,
  "data": {...},
  "message": "Human readable message"
}
```

### **7. Naming Conventions**

- **Database**: Vietnamese, PascalCase - `NHAN_VIEN`, `PHONG_BAN`
- **Code**: English, camelCase - `getEmployee()`, `employeeData`
- **Stored Procedures**: `sp_<action><entity>` - `sp_createEmployee`
- **Functions**: `fn_<name>` - `fn_TinhLuong`
