## 📋 Project Structure & Architecture Patterns

### **Mandatory 3-Layer Architecture**

```
Request Flow: Router → Controller → Service → Repository → Database
```

Each layer has a specific responsibility:

1. **Router Layer** (`routers/`)
   - Define HTTP endpoints (GET, POST, PUT, DELETE)
   - Apply middleware (authentication, authorization)
   - Delegate to controller

2. **Controller Layer** (`controllers/`)
   - Extract & validate request data
   - Call service method
   - Format and return HTTP response

3. **Service Layer** (`services/`)
   - **Core business logic** (calculations, validations, transformations)
   - Call repository methods
   - Handle errors and edge cases
   - Format response data

4. **Repository Layer** (`repositories/`)
   - **Data Access Layer (DAL)** only
   - Execute SQL queries and stored procedures
   - Return raw data from database
   - No business logic here

### **Key Pattern Examples**

#### ✅ CORRECT - Payroll Service (Business Logic)

```typescript
// services/payrollService.ts
payrollService = {
  generatePayroll: async (month, year) => {
    // ✅ BUSINESS LOGIC: Calculate salary, bonuses, deductions
    const rawData = await payrollRepository.getRawDataForPayroll(month, year);
    const processed = rawData.map((emp) => {
      const luongThucLanh =
        emp.LuongCoBan + emp.PhuCap + emp.Thuong - emp.KhauTruBHXH;
      return { ...emp, ThucLanh: luongThucLanh };
    });
    // ✅ PERSISTENCE: Call repository
    await Promise.all(
      processed.map((p) => payrollRepository.createPayrollRecord(p)),
    );
    return processed;
  },
};
```

#### ❌ WRONG - Business logic in Repository

```typescript
// ❌ DON'T DO THIS IN REPOSITORY
payrollRepository = {
  generatePayroll: async () => {
    // ❌ Business logic should be in service
    const luongThucLanh = luongCoBan + phucap + thuong - khauthru;
    await appPool.request().execute("sp_createPayrollRecord");
  },
};
```

## 🔐 Core Features & Patterns

### **1. Authentication & JWT**

- **Pattern**: Multi-step registration with OTP verification
- **Token**: JWT with 3-hour expiry + 7-day refresh token
- **OTP**: 6-digit code sent via Nodemailer
- **Password**: Encrypted with bcryptjs before database storage
- **Middleware**: `withUserConnection` validates JWT & creates per-user DB connection

**When adding authentication to new endpoints:**

```typescript
// In route
router.get("/protected", withUserConnection, controllerMethod);

// In service - access user from request
const service = async (req) => {
  const userId = req.userId; // Set by authMiddleware
  const connection = req.connection; // Per-user connection
};
```

### **2. Database Connection Pattern**

- **Connection Pool**: `appPool` from `config/db.ts`
- **Per-User Connection**: Azure SQL creates dynamic database user per login
- **Stored Procedures**: Executed via `appPool.request().execute("sp_name")`
- **Input Parameters**: Always use `.input()` to prevent SQL injection

**Correct DB Query Pattern:**

```typescript
const getEmployee = async (maNv) => {
  const result = await appPool
    .request()
    .input("MaNV", sql.VarChar, maNv)
    .query("SELECT * FROM NHAN_VIEN WHERE MANV = @MaNV");
  return result.recordset[0] || null;
};
```

### **3. Service Layer Validation**

Always validate input in service layer before DB operations:

```typescript
const createEmployee = async (data) => {
  // ✅ Validate required fields
  if (!data.manv || !data.hoten) {
    throw new Error("MANV and name are required");
  }

  // ✅ Validate business rules
  if (data.manv.length > 10) {
    throw new Error("MANV must be <= 10 characters");
  }

  // ✅ Check for duplicates
  const existing = await employeeRepository.getByMaNV(data.manv);
  if (existing) {
    throw new Error("MANV already exists");
  }

  // ✅ Then persist
  return await employeeRepository.createEmployee(data);
};
```

### **4. Error Handling Pattern**

```typescript
// In service
try {
  const result = await repository.getData();
  return result;
} catch (error) {
  if (error.message.includes("NOT FOUND")) {
    throw new Error("Resource not found");
  }
  throw error;
}

// In controller
try {
  const data = await service.method();
  res.json({ success: true, data });
} catch (error) {
  res.status(400).json({
    success: false,
    message: error.message,
  });
}
```

### **5. Pagination Pattern**

```typescript
// Controller
const page = parseInt(req.query.page) || 1;
const pageSize = parseInt(req.query.pageSize) || 10;
const data = await service.getPage(page, pageSize);

// Service
const getPage = async (page, pageSize) => {
  const offset = (page - 1) * pageSize;
  return await repository.getWithPagination(offset, pageSize);
};

// Repository
const getWithPagination = async (offset, pageSize) => {
  const result = await appPool
    .request()
    .input("Offset", sql.Int, offset)
    .input("PageSize", sql.Int, pageSize)
    .query(
      "SELECT * FROM TABLE ORDER BY ID OFFSET @Offset ROWS FETCH NEXT @PageSize ROWS ONLY",
    );
  return result.recordset;
};
```

### **6. Realtime Chat Pattern (Socket.IO)**

- **Connection**: Client connects via socket event
- **Rooms**: Chat rooms identified by roomId (direct, group, or project)
- **Events**: `chat:send_message`, `chat:receive_message`, `chat:join_room`
- **Persistence**: Messages stored in database via repository

- Password Change/Reset → Validation → Encryption → Update

## 🛠️ Common Development Tasks

### **Task: Add a New API Endpoint**

1. **Create Router** (`routers/<domain>Routes.ts`)

   ```typescript
   router.get("/api/new-resource", withUserConnection, newController.getAll);
   ```

2. **Create Controller** (`controllers/<domain>Controller.ts`)

   ```typescript
   const getAll = async (req, res) => {
     try {
       const data = await newService.getAll();
       res.json({ success: true, data });
     } catch (error) {
       res.status(400).json({ success: false, message: error.message });
     }
   };
   ```

3. **Create Service** (`services/<domain>Service.ts`)

   ```typescript
   const getAll = async () => {
     const data = await newRepository.getAll();
     return data;
   };
   ```

4. **Create Repository** (`repositories/<domain>Repository.ts`)

   ```typescript
   const getAll = async () => {
     const result = await appPool.request().query("SELECT * FROM TABLE_NAME");
     return result.recordset;
   };
   ```

5. **Register Route** in `app.ts` or `server.ts`
   ```typescript
   app.use("/api/new-resource", newRoutes);
   ```

### **Task: Add a Stored Procedure Call**

1. **Create Stored Procedure** in SQL Server (Database)

   ```sql
   CREATE PROCEDURE sp_CustomLogic
     @Parameter1 NVARCHAR(50)
   AS
   BEGIN
     SELECT * FROM TABLE WHERE Column = @Parameter1;
   END
   ```

2. **Call from Repository**

   ```typescript
   const customMethod = async (param1) => {
     const result = await appPool
       .request()
       .input("Parameter1", sql.NVarChar, param1)
       .execute("sp_CustomLogic");
     return result.recordset;
   };
   ```

3. **Expose via Service**
   ```typescript
   const customService = async (param1) => {
     const rawData = await repository.customMethod(param1);
     // Process business logic
     return rawData;
   };
   ```

### **Task: Add JWT Protected Route**

```typescript
// In route
router.post("/api/protected-action", withUserConnection, controllerMethod);

// In controller - user info is in req object
const protectedMethod = async (req, res) => {
  const userId = req.userId; // From JWT token

```

## 📚 Best Practices & Guidelines

### **✅ DO's**

1. **Always validate input** in service layer before DB operations
2. **Use TypeScript types** - Define interfaces for all data structures
3. **Parameterize SQL queries** - Use `.input()` to prevent SQL injection
4. **Handle errors gracefully** - Try-catch with meaningful messages
5. **Use stored procedures** for complex business logic in database
6. **Separate concerns** - Keep layers independent and testable
7. **Use pagination** for list endpoints to prevent data overload
8. **Cache frequently accessed data** (departments, positions, etc.)
9. **Add request/response logging** for debugging
10. **Document complex business logic** with comments

### **❌ DON'Ts**

1. **Don't put business logic in repository** - Repositories only access data
2. **Don't concatenate SQL strings** - Always use parameterized queries
3. **Don't hardcode config values** - Use environment variables
4. **Don't return all columns** - Select only needed columns
5. **Don't mix concerns** - Keep validation, transformation, persistence separate
6. **Don't ignore errors** - Always handle and log errors
7. **Don't create massive controller functions** - Delegate to service
8. **Don't use raw passwords** - Always hash with bcryptjs
9. **Don't expose internal errors to client** - Sanitize error messages
10. **Don't skip authentication** - Apply `withUserConnection` middleware

## 📝 Common File Templates

### **New Service Template**

```typescript
import <DomainRepository> from "../repositories/<domain>Repository";

const <domain>Service = {
  // ✅ Business logic methods
  getAll: async () => {
    const data = await <domain>Repository.getAll();
    return data;
  },

  create: async (data) => {
    // Validate
    if (!data.required_field) throw new Error("Missing required field");

    // Business logic
    const processed = { ...data, created_at: new Date() };

    // Persist
    return await <domain>Repository.create(processed);
  },
};

export default <domain>Service;
```

### **New Repository Template**

```typescript
import { appPool, sql } from "../config/db";

const <domain>Repository = {
  // ✅ Data access only
  getAll: async () => {
    const result = await appPool
      .request()
      .query("SELECT * FROM TABLE_NAME");
    return result.recordset;
  },

  getById: async (id) => {
    const result = await appPool
      .request()
      .input("ID", sql.Int, id)
      .query("SELECT * FROM TABLE_NAME WHERE ID = @ID");
    return result.recordset[0] || null;
  },

  create: async (data) => {
    await appPool
      .request()
      .input("Field1", sql.NVarChar, data.field1)
      .execute("sp_create<Domain>");
  },
};

export default <domain>Repository;
```

### **New Controller Template**

```typescript
import <domain>Service from "../services/<domain>Service";

const <domain>Controller = {
  getAll: async (req, res) => {
    try {
      const data = await <domain>Service.getAll();
      res.json({ success: true, data });
    } catch (error) {
      res.status(400).json({ success: false, message: error.message });
    }
  },

  getById: async (req, res) => {
    try {
      const { id } = req.params;
      const data = await <domain>Service.getById(id);
      if (!data) {
        return res.status(404).json({ success: false, message: "Not found" });
      }
      res.json({ success: true, data });
    } catch (error) {
      res.status(400).json({ success: false, message: error.message });
    }
  },

  create: async (req, res) => {
    try {
      const data = await <domain>Service.create(req.body);
      res.status(201).json({ success: true, data });
    } catch (error) {
      res.status(400).json({ success: false, message: error.message });
    }
  },
};

export default <domain>Controller;
```
