# Hướng Dẫn Cấu Hình Hệ Thống CDN Media (danghoa.erp)

Tài liệu này ghi chú lại chi tiết kiến trúc và cách thiết lập hệ thống phân phối nội dung (CDN) lưu trữ hình ảnh, media, và file tĩnh phục vụ riêng cho dự án Web/ERP của bạn.

---

## 1. Tổng Quan Hệ Thống CDN

Thay vì lưu trữ file hình ảnh rác trực tiếp trên source code Web/ERP gây nặng máy chủ và khó backup, chúng ta tách riêng toàn bộ file media sang hệ thống MinIO. 

* **Mục đích:** Lưu trữ file tập trung, trả file (serve file) cho người dùng cuối (User) bằng tốc độ tối đa thông qua bộ nhớ đệm Cache.
* **Tên miền phục vụ:** `https://cdn.danghoa-erp.site`
* **Công nghệ sử dụng:** Cloudflare (DNS + HTTPS) + Nginx (Proxy & Cache) + MinIO (S3 Core Storage).

---

## 2. Thiết Lập Lưu Trữ (MinIO Bucket)

Bucket này được cấu hình độc lập hoàn toàn với bucket cá nhân để đảm bảo an toàn.

* **Tên Bucket:** `danghoa.erp`
* **Giới hạn dung lượng (Quota):** `10 GB` (Hệ thống sẽ từ chối nhận thêm file từ web nếu đầy 10GB).
* **Quyền Truy Cập (Access Policy):** `Public Read` (hoặc `download`). Bất cứ ai có đường link URL đều có thể xem/tải ảnh mà không cần đăng nhập, nhưng **không thể** tự ý upload hay xóa ảnh nếu không có Secret Key.

---

## 3. Cấu Hình Hạ Tầng Mạng (Cloudflare Zero Trust)

Bởi vì máy chủ đặt phía sau tường lửa và chặn các cổng kết nối Inbound, hệ thống không sử dụng bản ghi DNS thông thường mà sử dụng công nghệ **Cloudflare Tunnel (cloudflared)** để xuyên tường lửa một cách bảo mật.

1. **Đường hầm Cloudflare (Tunnel):**
   * Một dịch vụ phần mềm `cloudflared` chạy ngầm trên máy chủ, thiết lập kết nối mã hóa Outbound an toàn từ trong ra ngoài tới Cloudflare.
   * Tunnel được sử dụng chung cho toàn bộ hệ thống ERP (có tên là `huit-erp-backend`).
2. **Định tuyến Public Hostname:**
   * Tên miền `cdn.danghoa-erp.site` được cấu hình dưới dạng Public Hostname bên trong Cloudflare Zero Trust.
   * Cloudflare tự động bọc HTTPS ở vòng ngoài, sau đó đẩy luồng dữ liệu (traffic) chui qua đường hầm, đi thẳng vào cổng **`9080`** (bằng giao thức HTTP) trên máy chủ nội bộ (`127.0.0.1:9080`) nơi Nginx đang đợi sẵn.
   * **Ưu điểm Tuyệt đối:** Không cần mở bất kỳ Port nào trên Router hay Tường lửa của máy chủ, ngăn chặn hoàn toàn nguy cơ bị quét IP và tấn công DDoS vào hệ thống nhà.

---

## 4. Cấu Hình Phân Phối (Nginx Proxy)

Nginx đóng vai trò là một màng lọc và tăng tốc độ (Cache) đứng trước MinIO.

* Nginx lắng nghe ở cổng `9080` và chấp nhận mọi tên miền (`server_name _;`).
* **Định tuyến:** Bất kỳ đường link nào có chứa tiền tố `/media/` đều được Nginx chui vào lấy data từ bucket `danghoa.erp`.
* **Cơ chế Cache:** Nginx được thiết lập lưu cache các file tĩnh lên đến 10GB trên RAM/Ổ cứng và giữ trong vòng 30 ngày. Điều này giúp giảm tải cực lớn cho MinIO và Web chạy cực nhanh.

---

## 5. Hướng Dẫn Sử Dụng (Dành cho Lập trình viên)

Từ bây giờ, quy trình xử lý file trên code của hệ thống ERP sẽ diễn ra như sau:

### Cách lấy Link ảnh (Dùng để hiển thị)
Bất kỳ file nào (ví dụ `anh-san-pham-1.jpg`) được nằm trong bucket `danghoa.erp` sẽ có một URL duy nhất và bất biến.
👉 **Định dạng URL tĩnh lưu vào Database:**
```text
https://cdn.danghoa-erp.site/media/anh-san-pham-1.jpg
```
Lập trình viên chỉ cần lấy link này gán vào thẻ `<img src="...">` của HTML là ảnh sẽ hiển thị ngay lập tức.

### Cách Upload File
* Quản trị viên: Có thể upload tay bằng cách dùng RaiDrive hoặc Web UI (Console) ném thẳng file vào thư mục `danghoa.erp`.
* Code ERP: Cần tích hợp thư viện AWS S3 SDK (Nodejs/PHP/Python...). Khi code kết nối, bắt buộc phải dùng IP nội bộ hoặc thông tin Key Private, tuyệt đối không lộ Secret Key ra phía Frontend (Browser).
